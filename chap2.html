DISCIPLINE 02

Ⅱ 赤石時間论

本章では、赤石回路の駆動順序（更新順序）を支配する時間概念、および内部処理フェーズにおけるコンポーネント特性を厳密に体系化します。

1. ティック理論TICK THEORY

ゲームティック (gt) II-Gt

Minecraft Java Editionの根底を流れる最小の時間単位は、1秒間に20回実行される ゲームティック（Game Tick / gt） です。1 gt = 0.05秒 であり、この内部は複数の処理フェーズに細分化されています。

レッドストーンティック (rt) II-Rt

リピーターやトーチなどの遅延要素は、2ゲームティックを基準とする レッドストーンティック（Redstone Tick / rt） を基準に動作します。1 rt = 2 gt = 0.1秒 です。

2. 3大コンポーネント分類COMPONENTS

PLC / STC / BEC 定義 II-Cmp

赤石素子はその処理フェーズによって、以下の3つに厳密に分類・定義されます。

FRouT 素子分類
  • PLC (Phaseless Component)：遅延を挟まず、その場で即時に信号を伝播。
  • STC (Schedule Tick Component)：指定gt経過後の「Scheduled Ticks フェーズ」で駆動。
  • BEC (Block Event Component)：最終盤の「Block Events フェーズ」でイベントを処理。
