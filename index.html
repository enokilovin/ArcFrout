根本理念｜BASIC CONCEPT

4 CONCEPTS
  1. 赤石コミュニティの基礎底上げ
    • 赤石の仕様にまつわる「暗黙知」を明らかにします。その知識を、実践的または理論的な視点から理解することで「赤石界の発展」に尽力します。
  2. 一般向け解説資料の補足・訂正・根拠の明示
    • WEB上にはMinecraft Wikiに代表される解説資料が無数にあります。意識的または無意識的にカットされている内容を浮き彫りにして「知識の是正」を試みます。
  3. 分野横断的かつ体系的な内容整理
    • 赤石にまつわる知識は無数にあり、その知識の応用先も数多くあります。断片的ではなく横断的に参照できるよう資料を体系化することで「知識の拡大」に取り組みます。
  4. 共著による専門性の向上
    • 主宰者（@enokilovin）によって権限を与えられた有志たちは、記事の作成・編集・公開ができるようになります。それぞれ専門領域をもつ有志によって「知識の深化」がもたらされます。
    • ただし、権限の付与対象は主宰者の独断に委ねられていますので、その点はご了承ください。情報の補足や誤情報に対する指摘など、GitHub Issuesで気兼ねなくフィードバックしていただけると幸いです！

Ⅰ 赤石初歩論｜RS-ELEMENTS（Chap.I）

赤石の基本仕様と環境構築にまつわる初等知識—— 赤石回路を構成する要素（信号や隣接更新など）について広く浅く確認します。初心者がつまずきやすい赤石の謎（例外的な挙動＝バグ）にも触れながら、赤石を遊び尽くすための環境構築も学びます。

I-Sig信号 ( SIGNAL )

赤石の信号について、ON/OFFの概念や信号強度、動力源化と活性化の違いといった視点から眺めます。

I-Con信号接続 ( SIGNAL CONNECTION )

信号の伝わり方について、直接的または間接的な接続方法の違いを理解します。

I-Upd隣接更新 ( NEIGHBOR UPDATE )

ブロックの状態変化がまわりに伝播する「アップデート」の仕組みを紐解きます。

I-Cat赤石素子分類 ( RS-COMPONENT CATEGORIES )

ブロックの性質にもとづいて赤石素子を分類します。

I-Cpt赤石素子 ( RS-COMPONENTS )

リピーターやピストンなどの赤石素子にまつわる個別仕様をまとめます。

I-Mys赤石の謎 ( RS-MYSTERIES )

方角依存、準接続、透過ブロックの挙動など、直感に反する仕様について理解することで、実践的な力を身につけます。

I-Cmdコマンド ( COMMANDS )

赤石回路の開発やその検証に役立つ必須コマンドを紹介します。

I-Env環境構築 ( ENVIRONMENT SETUP )

赤石用ワールドの構築からルール設定まで把握して、開発に最適な環境を整えます。

I-ModMOD ( MODIFICATIONS )

Carpet, Litematica, MiniHUDなど、赤石の開発と検証を最大限補助するMODについて紹介します。

I-Rspリソースパック ( RESOURCE-PACKS )

信号強度の可視化やブロックの設置方向の判別など、視認性を上げて開発効率を高めるリソースパックについて紹介します。

I-SnsSNS ( SOCIAL NETWORKING SERVICES )

国内外の赤石コミュニティを知り、情報を収集して、知見を共有する方法についてまとめています。

Ⅱ 赤石時間論｜RS-CHRONOLOGY（Chap.II）

赤石の処理順と更新順序にまつわる理論—— 赤石の挙動を「ゲームティック」という時間単位で捉え、処理順序・更新順序を軸にした「動作順の解析」を試みます。同じ回路でも配置や向きによって挙動が変わる場合がある理由、その説明のために処理順序などを書き下すための記述法について確かめます。

II-Gtickゲームティック ( GAMETICK )

時間の基本単位であるゲームティック（gt）について、リアルタイムとの違いや各フェーズなどに触れながら理解を深めます。

II-PrOrd処理順序 ( PROCESSING ORDER )

同一ティック内における各処理フェーズ（PI, ST, BE, EN, TE）の実行サイクルを詳述します。

II-UpOrd更新順序 ( UPDATE ORDER )

同一フェーズ内で複数のブロックが同時に動くとき、何が優先されるかをアップデートの順序という視点から眺めます。

II-Direc方角依存性 ( DIRECTIONALITY )

「装置を90度回転すると故障する」といった方角にまつわる動作模様の違いとその対処法を、アップデートの送受信から紐解きます。

II-Locat座標依存性 ( LOCATIONALITY )

「装置の場所を移すと故障する」といった位置座標にまつわる動作模様の違いとその対処法を、HashSetという仕組みから紐解きます。

II-ChGph赤石記述法 ( RS-CHRONOGRAPHY )

複雑な処理順や更新順を正確に言語化（可視化）するために考案された、タイムライン形式での専用記法「RSC」を紹介します。

Ⅲ 赤石負荷論｜RS-EFFISCIENCE（Chap.III）

実負荷とその軽減にまつわる理論—— 赤石系の処理とその負荷を「ロード／ラグ」の視点から眺めます。クライアントの負荷とサーバーの負荷を区別しながら、それぞれ適切な計測法をもちいて負荷を数値化・比較・最適化するまで考えます。サバイバルを快適に過ごすためにも重要です。

III-LdLgロード / ラグ ( LOAD / LAG )

負荷の分類から始めて、それぞれの負荷の影響（ラグ）や計測法について理解します。

III-InLd内的負荷要因 ( INTERNAL LOAD )

赤石素子、光や音、チャンクにまつわる処理など、ワールド内部で発生する処理の負荷要因を探ります。

III-ExLd外的負荷要因 ( EXTERNAL LOAD )

オートセーブ、バージョンの違い、MODの有無など、ワールド外部で起こりうる処理の負荷要因を探ります。

III-CltLgクライアント負荷計測法 ( CLIENT-LAG )

画面のレンダリングやパーティクル処理などがクライアント側に与える負荷を計測します。

III-SrvLgサーバー負荷計測法 ( SERVER-LAG )

アップデート送信数や信号源探索、形状変化、当たり判定の変化などがサーバー側に与える負荷を計測します。

III-LgCom負荷比較 ( LAG COMPARISON )

さまざまな負荷を各素子や各環境のレベルで比較してまとめることで、次の負荷軽減法に繋げていきます。

III-LgOpt負荷軽減法 ( LAG OPTIMIZATION )

以上の検証にもとづき素子の置き換えやMODを用いるなどして、総合的な負荷軽減策を提案します。

Ⅳ 赤石技術論｜RS-TECHNOLOGY（Chap.IV）

赤石技術にまつわる理論と実践—— 赤石回路の設計法から始まり、無遅延通信やストレージ技術などの「応用体系」をまとめます。あわせて「なぜこの技術が可能なのか」を理論的な視点から考えることで、装置が故障した場合の対処法をみずから考えられるようになります。

IV-Arch赤石回路設計法 ( RS-ARCHITECTURE )

赤石回路設計における小型化、高速化、並列化、サバイバルでの壊れにくさ、動作デバッグの手法などをまとめています。

IV-InsCm無遅延通信 ( INSTANT COMMUNICATION )

リピーター、レール、コンパレーターなどを利用して、信号を無遅延で（瞬時に）伝える技術について解説します。

IV-WlsCm無線通信 ( WIRELESS COMMUNICATION )

日照センサーやアイテムエンティティ等を利用したワイヤレス通信法について解説します。

IV-Suprサプレッション ( SUPPRESSION )

アップデートのサプレッションやスキップなど、ゲームの更新処理を意図的に抑制・遮断する高度な技術を扱います。

IV-ChLdチャンクローディング ( CHUNK LOADING )

特定回路をつねに動作させるためのチャンク読み込み維持技術について理解を深めます。

IV-PiTchピストン応用技術 ( PISTON TECH )

自動ドア、エレベーター、フライングマシン、ピストンボルトなどのピストンにまつわる応用技術について紹介します。

IV-EnTchエンティティ応用技術 ( ENTITY TECH )

レール増殖やTNT増殖、TNTキャノンや3Dディスプレイなどのエンティティにまつわる応用技術を紹介します。

IV-Strgストレージ技術 ( STORAGE TECH )

水流、ホッパー、ドロッパー、論理回路などを複合的に組み合わせた、高度なアイテム輸送・保管技術を紹介します。

IV-Maze迷路生成 ( MAZE GENERATOR )

赤石回路のみでアルゴリズムを処理し、自動で迷路を生成する回路の仕組みを明らかにします。

Ⅴ 形式論理学｜FORMAL RS-LOGIC（Chap.V）

論理回路にまつわる初等知識—— 赤石回路を「論理回路」の視点から眺めます。数の表現（十進法や二進法など）を学びながら、マインクラフトの世界で記憶装置をつくる方法や、加減乗除の計算がどうすれば可能になるか等々について考えます。

V-Pvs 位取り記数法 ( PVS; PLACE VALUE SYSTEM )

赤石で「数」を扱うために、2進数、10進数、16進数、2進化10進数（BCD）の表現方法を学びます。

V-Boolブール論理 ( BOOLEAN LOGIC )

真と偽という論理の世界を「数」の世界に繋ぎ合わせる、論理演算の基礎を扱います。

V-LogOp論理演算 ( LOGICAL OPERATION )

組み合わせ論理（AND, OR, NOTなど）による演算と、順序論理による記憶の仕組みを解説します。

V-ArtOp算術演算 ( ARITHMETIC OPERATION )

加減乗除を赤石で実現する方法や、実数の表現方法を紹介します。

V-Grayグレイコード ( GRAY CODE )

エラーに強い符号化技術の概要を学びます。

Ⅵ 計算機科学｜RS-COMPUTER SCIENCE（Chap.VI）

赤石論理回路にまつわる発展知識—— 複雑な計算機をつくるために、それを構成するさまざまな回路について学びます。エンコーダ、デコーダ、カウンタ、メモリ、ディスプレイなどを組み立てて、数の入力・計算・表示までの道のりを示します。

VI-Trans信号伝達 ( SIGNAL TRANSMISSION )

各数値表現、各パルス長、直列並列、無遅延の信号伝達などについて理解を深めます。

VI-EnDecエンコーダ / デコーダ ( ENCODER / DECODER )

データの圧縮や復元、相互変換などをおこなう回路を設計します。

VI-Countカウンタ ( COUNTER )

パルスを検出するたびに、内部の数値を1ずつ加算・維持する回路を設計します。

VI-Mem 4. メモリ ( MEMORY )

データを一時的あるいは永続的に保持する記憶装置を設計します。

VI-ShRegシフトレジスタ ( SHIFT REGISTER )

データを一定方向にシフトさせる記憶装置を設計します。

VI-Dispディスプレイ ( DISPLAY )

7セグメント、16セグメント、ビットマップによるデータのディスプレイ装置を設計します。

VI-BcdBCD変換器 ( BCD CONVERTER )

計算しやすい2進数と、ディスプレイに表示しやすい10進数、この中間にある「2進化10進数（BCD）」にデータを変換する装置を設計します。

VI-Add加算器 ( ADDER )

赤石で「加算」を実現するための半加算器や全加算器を知ったうえで、CLAやCCAなどの計算高速化技術を学びます。

VI-Subt減算器 ( SUBTRACTOR )

補数表現などを利用して、加算器をベースに減算を実現する回路を設計します。

VI-Mult乗算器 ( MULTIPLIER )

加算の反復やシフト演算によって、赤石で乗算を実現します。

VI-Div除算器 ( DIVIDER )

減算の反復やシフト演算によって、赤石で除算を実現します。

VI-Alu算術論理演算装置 ( ALU; ARITHMETIC LOGIC UNIT )

さまざまな演算を総合的に処理する、計算機の中枢を構築します。

VI-InsTh無遅延理論 ( INSTANT THEORY )

無遅延計算機の仕組みを理解します。

VI-Miscその他 ( MISC )

その他、計算機科学のカテゴリに属する応用回路をまとめます。

Ⅶ 赤石小事典｜RS-ARCHIVES（Chap.VII）

赤石大系：歴史・術語集・資料—— 理論や技術の「体系的な参照元」として、赤石の歴史・術語集・ソースコードなどを集約します。赤石基礎論のデータベースの役割も担います。共同執筆のための指針もまとめておきます。

VII-ComHs赤石比較史 ( RS COMPARATIVE HISTORY )

Java版と統合版の仕様差異（パリティ）や、バージョン移行にともなう歴史の変遷、世界各国の赤石情勢を扱います。

VII-DisHs赤石発見史 ( RS DISCOVERY HISTORY )

無線通信などの歴史的な技術が発見された経緯をまとめています。

VII-Glos術語集 ( GLOSSARY )

赤石界隈で登場する用語の定義、訳語の索引や略語の対応表もまとめる辞書です。

VII-Bugバグ一覧 ( BUG REGISTRY )

開発するうえで知っておくべき「例外的仕様」をまとめます。

VII-Codeソースコード ( SOURCE CODE )

ゲーム内コードの解析方法やその注意点をまとめます。

VII-Bench負荷比較表 ( LAG BENCHMARKS )

赤石素子の負荷を測定、一覧化したベンチマーク資料です。
