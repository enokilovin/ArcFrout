赤石基礎論：赤石にまつわる普遍学

FRouT : Fundamental Redstone Theory in Minecraft Java

根本理念 BASIC CONCEPT

本論は、Minecraft Java Editionにおけるレッドストーン論理およびメカニクスを包括的かつ体系的に整理し、コミュニティへ学術的基盤を提供することを目的としています。

【基本指針】

  • 赤石コミュニティの〈基礎〉底上げ
  • 一般向け解説資料の補足・訂正・根拠の明示
  • 分野横断的かつ〈体系〉的な内容整理

Ⅰ 赤石初歩論 RS-ELEMENTS

1. 信号 I-Sig

レッドストーン信号は、デジタル論理の基礎となる オフ / オン (0 / 1) の2状態、および 0から15の信号強度 によって規定されます。

信号の伝播は隣接するブロックへの更新を伴い、回路全体の挙動を決定づける最小単位となります。

2. 動力源化 I-Pow

ブロックがエネルギーを持っている状態を動力源化と呼び、これには hard-powered（強-動力源化）と soft-powered（弱-動力源化）の厳密な区別が存在します。

3. 隣接更新 I-Upd

赤石回路が動作する際、周囲のブロックに対して状態の変化を伝えるプロセスを隣接更新と呼びます。これらは内部処理フェーズにおいて、PLC（Phaseless）、STC（ScheduleTick）、BEC（BlockEvent）の特性に応じて制御されます。

Ⅱ 赤石時間論 RS-CHRONOLOGY

1. ゲームティック II-Gt

1秒間に20回処理されるゲームティック(Game Tick)は、内部で複数のフェーズに分かれています。

2. レッドストーンティック II-Rt

多くの赤石コンポーネントが基準とする2ゲームティック（0.1秒）単位の時間概念を指します。
