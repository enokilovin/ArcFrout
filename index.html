赤石基礎論：赤石にまつわる普遍学

FRouT : Fundamental Redstone Theory in Minecraft Java

本論は、Minecraft Java Editionにおけるレッドストーン論理およびメカニクスを包括的かつ体系的に整理し、コミュニティへ学術的基盤を提供することを目的とした研究アーカイブです。ソースコードに準拠した厳密な定義に基づき、回路を計算機科学・形式論理学の次元へと昇華させます。
