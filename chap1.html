＃I-Sig

信号 ( SIGNAL )

01. オフ / オン ( off / on ) = ( 0 / 1 )

マインクラフトの世界にあるブロックは、オフまたはオンのどちらかの状態をつねにもっています。動力を受け取っていない状態を「オフ」と呼び、受け取っている状態を「オン」と呼びます。たとえば、RSダストはオフのとき光っていませんが、オンのとき光っています。

動力を生みだす方法や動力源となるブロックは多種多様です。レバーを引く、ボタンを押すなど多々あります。ただ赤石回路を動かすためには、その動力をいろいろな場所に送らなければいけません。それを送ってくれるのが「信号」です。信号は 2 種類あって、オンにするための信号を「**オン信号**」と呼び、オフにするための信号を「**オフ信号**」と呼んで区別しておきましょう。たとえば、ピストンはオン信号が送られると伸展し始めて、そのオンの状態でオフ信号が送られると収縮し始めます。

あるブロックにおいて、オフ信号が送られている状態を「オフ」「0」「LOW」と呼び、オン信号が送られている状態を「オン」「1」「HIGH」と呼ぶことがあります。この別称はとりわけ論理回路のなかで重要になるので、〈ブール論理｜V-Bool〉という文書であつかうことにしましょう。とにかく、この二値（0 / 1）を上手にあつかうことができれば、マインクラフトの世界で複雑な自動装置や計算機などを作ることができるのです！

02. 信号強度 ( signal strength ) = ( 0-15 )

先ほど冒頭で「ブロックは、オフまたはオンのどちらかの状態をつねもしています」と述べました。これはデジタル（二値）の視点なのですが、それとは違う**アナログ（多値）**の視点もマインクラフトでは重要になります。アナログ信号、つまり「連続的な値をもつ信号」と深い関わりをもつブロックがRSダストとコンパレーターです。

RSダストは光っている状態と光っていない状態をもっていますが、オン信号が送られて光った状態のなかでも光り方が様々あります。この光り方の違いは、信号の強さの違いによって生じるものです。この信号の強さのことを「**信号強度**」と呼びます。

まず信号強度は 0 から 15 まであります。そのうち、強度 0 の信号がオフ信号のことで、それ以外の強度 1 から 15 までの信号がオン信号のことです。RSダストの光り方は、受け取っている信号強度の違いによって段階的に変化します。一方、コンパレーターの光り方に段階はありませんが、この全 16 通りの強度を保持したまま信号を出力することができます。

一方、リピーターは信号強度を保持できず、オフ信号が送られると信号強度「0」を出力して、オン信号が送られると信号強度「15」にリセットして出力します。このように、RSダストとコンパレーター以外のブロックはすべてデジタルな動きをするわけです。

なお英語圏では、信号強度のことを「ss」や「pl」と略すことがあります。主に見かけるのは「ss」のほうで、たとえば「ss10」は「信号強度 10」を意味するので覚えておきましょう。

03. 動力源化 ( powered )

動力を生みだす方法や動力源となるブロックの話に移りましょう。ブロックのなかには、もともと動力を生みだすために用意されたもの（ボタンなど）もあれば、そうではないものもあります。ただ動力を生みだせないブロックでも、その種類によってはオン信号が送られることによって動力源の代わりになるブロックもあります。それはRSブロックのように、隣接するリピーターやトラップドア等々に対してオン信号を伝えることができるようになるわけです。これを「動力源化」と呼ぶことにしましょう。

動力源化できる種類のブロックは「導体ブロック」あるいは単に「導体」と呼ばれています。たとえば、丸石、RSランプ、ドロッパーなどは導体です。一方、ガラス、半ブロック、ピストンなどは動力源化できない「不導体ブロック」あるいは単に「不導体」と呼ばれ、オフ信号しか通さない絶縁体として働きます。いずれにしても、信号強度が維持される点に注意してください。

さて、オン信号が送られた導体は動力源の代わりになるわけですが、何のブロックによってオン信号が送られたかにおうじて、オン信号をまわりにどう伝えるかが変わってきます。とりわけRSダストにオン信号を伝えるか伝えないかが変わってきます。この違いを理解するために「強-動力源化」と「弱-動力源化」というふうに区別して確かめていきましょう。

強-動力源化 ( hard-powered )

リピーター、コンパレーター、オブザーバーなどによって直接オン信号が送られた導体は「強-動力源化」します。この状態だと、隣接するトラップドア等々だけでなくRSダストにもオン信号を伝えることができます。ただし、他の導体を動力源化することはできません。

弱-動力源化 ( soft-powered )

RSダストによって直接オン信号が送られた導体は「弱-動力源化」します。この状態だと、隣接するトラップドア等々にオン信号を伝えることはできますが、別のRSダストにはオン信号を伝えることができません。弱-動力源化の場合、裏を返せば、オン信号をRSダストに伝えないまま他のブロックに伝えることができるので、この範囲の狭さをうまく使って回路を組むこともよくあります。

状態 RSダスト以外から受信 RSダストから受信 RSダスト以外に送信 RSダストに送信
強-動力源化 ✓ - ✓ ✓
弱-動力源化 - ✓ ✓ -

04. 活性化 ( activated )

ブロックのなかには、送られた信号に反応できるものがあります。たとえばTNTがオン信号に反応して爆発する、ピストンがオフ信号に反応して縮み始める等々です。このように、ブロックの種類によっては信号に反応して起動する、特有のアクション（状態や外見が変わるなど）を起こすものがあります。これを「活性化」と呼びます。

活性化できる種類のブロックを「起動素子」と呼ぶことにしましょう。ここで注意が必要なのは、起動素子かつ導体**である（活性化もできて動力源化もできる）ようなブロックがあることです。これに該当するのはRSランプやドロッパーで、状態としては以下の 4 通りの組み合わせがありえます。

状態分類 ① ② ③ ④
活性化 - ✓ - ✓
動力源化 - - ✓ ✓
  • ① 活性化も動力源化もしていない状態：これはオフ信号が送られている状態です。
  • ② 活性化しているが動力源化していない状態：これはたとえば導体を介してオン信号が送られている状態です。
  • ③ 活性化していないが動力源化している状態：一見「矛盾」しています。オン信号が送られて動力源化しているはずなのに、活性化できていない状態だからです。しかし、実際は可能です。
  • ④ 活性化も動力源化もしている状態：これはたとえばリピーターによって直接オン信号が送られている状態です。

05. 起爆剤 ( activation trigger )

活性化のためには信号が送られるだけでは不十分で、その信号に反応するための「起爆剤」も必要になります。その起爆剤のことを「隣接更新」と呼びます。

起動素子は、隣接更新を受け取らないかぎり活性化することはありません。言いかえると、起動素子自身が**今どのような状態になるべきか**は隣接更新を受け取ってはじめて判定されるわけです。一方、動力源化については隣接更新が不要です。この「**信号と起爆剤の分離**」という仕様をうまく使うことで、先ほどの「③活性化していないが動力源化している状態」をつくりだすことが可能になります。

＃I-Con

信号接続 ( SIGNAL CONNECTION )

01. 接続 ( connection )

「接続」というのは、あるブロックに対して信号が送られること、または信号が送られて状態変化できるようになることです。この接続方法には「**直接続**」と「**間接続**」の2種類があります。

02. 直接続 ( direct connection )

「直接続」の定義は、あるブロックに対して 1 マス先から信号が送られることです。ブロックと動力源が隣接している状態、および動力源化した導体とつながっている状態を指します。

03. 間接続 ( indirect connection )

「間接続」の定義は、あるブロックに対して 2 マス先から動力を受け取っている状態です。間接続可能なブロックは 4 種類（RSダスト・ピストン・ドロッパー・ディスペンサー）に限られます。RSダスト限定のものを「**斜め間接続**」、それ以外を「**準接続（QC）**」と呼びます。

斜め間接続 ( diagonally indirect connection )

RSダストが斜め上下にある別のRSダストと接続するパターンです。水平方向や上下に2マス離れた接続はできません。導体や不導体の介入によって以下の切断パターンが発生します。

  • （ⅰ）水平方向が「導体」の場合：斜め下からの動力を受け取ることができません（完全切断）。ただし、中心のRSダストと導体上のRSダストは斜め同士で双方向に信号を送りあえます。
  • （ⅱ）水平方向が「不導体」の場合：斜め上からの動力を受け取ることができません（部分的切断）。不導体の上に置かれている斜め上のRSダストに対し、中心のRSダストは一方向（斜め上向き）にのみ信号を送ることができます。

上向き間接続 ( upwards indirect connection = QC / 準接続 )

ピストン、ドロッパー、ディスペンサー限定で、斜め上もしくは 2 マス上の動力源と接続する挙動です。海外では **quasi connectivity (QC)** と名づけられており、歴史的にはバグから「意図された仕様」へと昇格した背景を持ちます。これによって非常に高度な回路構築が可能になります。

＃I-Upd

更新順序 ( UPDATE ORDER )

01 隣接更新 ( neighbour update )

隣接更新とは、ブロック単位での変化を伝える仕組みです。変化が起きた際、①更新を**瞬時に**送って、②受け取ったブロックが自身の状態をチェックし、③必要があれば状態を変えます。この連鎖を「更新連鎖」と呼び、秩序だった規則（**更新順序 update order**）に基づいて処理されます。これを完全に掌握することで、方角依存や座標依存の完全な制御が可能になります。

隣接更新の種類と役割 ( BU / SU / CU )

  • a. BU ( block update )：オブザーバー以外の赤石系素子を作動させる更新。RSダストが強度を変化させた場合、これを起点にBUが瞬時に連鎖します。
  • b. SU ( state update )：フェンスなどの形状（shape）変化、不適合によるアイテム化、およびオブザーバーの起動を担当する更新。RSダストはSUを受け取っても信号強度の再計算は行わず、結線の確認（形状変化）を行います。

＃I-CCat / ＃I-Cpt

赤石素子と分類 ( REDSTONE COMPONENTS )

赤石装置はすべて「赤石回路と何らかの仕掛け」で成り立ち、赤石回路は「**赤石素子＋動力信号**」で構成されます。素子は物理的なもの、信号は情報的なものです。

01. 赤石素子の定義分類

  • 赤石基本素子 ( brc - basic rs-component )：[入力 → 状態変化 (→ 出力)] の構造を持つブロック（ボタンやピストンなど）。
  • 赤石応用素子 ( arc - applied rs-component )：基本素子を補助できるもの。ブロックに限らず、ボート、トロッコ、アーマースタンドなどの「エンティティ」も含まれます。

02. 基本素子 (brc) の3大分類

  • 動力素子 ( pc - power component )：動力を「生む」もの（レバー、ボタン等）。
  • 伝送素子 ( tc - transmission component )：動力を受けて自身が変わり、周囲に伝えるもの（RSダスト、リピーター、コンパレーターの3種のみ）。
  • 作動素子 ( mc - mechanism component )：動力を受けて特有のアクションを起こすもの（ピストン、ドロッパー、TNT等）。

03. 複合素子 ( cc - composite component )

基本素子としての機能と、応用素子としての属性（導体など）をあわせもつ二面性ブロックです。

  • 動力素子 × 導体素子 ( cpc )：ターゲットブロックがこれに該当。
  • 作動素子 × 導体素子 ( cmc )：ドロッパー、ディスペンサー、コマンドブロックなどがこれに該当。
＃I-Env

環境構築 ( ENVIRONMENT SETUP )

01 シングルプレイ ( csp; creative single play )

厳密な論理検証を行うための赤石開発向けシングルワールドの構築プロセスです。

  • α 起動構成 ( game setup )：ゲームディレクトリの分離、検証バージョンに応じた起動構成の管理、およびJVM引数によるメモリ最適化。
  • β ワールド構成 ( world setup )：不要なエンティティ負荷を排除するための難易度設定（ピースフル）や、構造物生成の最適化。
  • γ クライアントMOD ( client mod )：処理フェーズの可視化や、論理検証に不可欠な各種テクニカルMOD（MiniHUD、WorldEdit等）のセットアップ。
