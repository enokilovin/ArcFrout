信号

赤石回路を構成する最も根本的な要素「信号」の基本仕様、強度、伝播の仕組みを整理します。

オフ / オン ( off / on ) = ( 0 / 1 )

マインクラフトの世界にあるブロックは、オフまたはオンのどちらかの状態をつねにもっています。動力を受け取っていない状態を「オフ」と呼び、動力を受け取っている状態を「オン」と呼びます。たとえば、RSダストはオフのとき光っていませんが、オンのとき光っています。

動力を生みだす方法や動力源となるブロックは多種多様です。レバーを引く、ボタンを押すなど多々あります。ただ赤石回路を動かすためには、その動力をいろいろな場所に送らなければいけません。動力を送ってくれるのが「信号」です。信号は 2 種類あって、オンにするための信号を「オン信号」と呼び、オフにするための信号を「オフ信号」と呼んで区別します。たとえば、ピストンはオン信号が送られると伸展し始めて、そのオンの状態でオフ信号が送られると収縮し始めます[1]。

あるブロックにおいて、オフ信号が送られている状態を「オフ」「0」「LOW」と呼び、オン信号が送られている状態を「オン」「1」「HIGH」と呼ぶことがあります[2]。この別称はとりわけ論理回路のなかで重要になるのでブール論理｜V-Boolという文書であつかうことにしましょう。とにかく、この二値（0 / 1）を上手にあつかうことができれば、マインクラフトの世界で複雑な自動装置や計算機などを作ることができるのです！

信号強度 ( signal strength ) = ( 0-15 )

先ほど「ブロックは、オフまたはオンのどちらかの状態をつねにもっています」と述べました。これはデジタル（二値）の視点とも言えるのですが、それとは違うアナログ（多値）の視点もマインクラフトでは重要になります。アナログ信号、つまり「連続的な値をもつ信号」と深い関わりをもつブロックがRSダストとコンパレーターです。

RSダストは光っている状態と光っていない状態をもっていますが、オン信号が送られて光った状態のなかでも光り方が様々あります。この光り方の違いは、信号の強さの違いによって生じるものです。この信号の強さのことを信号強度と呼びます。

まず信号強度は 0 から 15 まであります。そのうち、強度 0 の信号がオフ信号のことで、それ以外の**強度 1 から 15 まで**の信号がオン信号です。RSダストの光り方は、受け取っている信号強度の違いによって段階的に変化します。一方、コンパレーターの光り方に段階はありませんが、この全 16 通りの強度を保持したまま信号を出力することができます[3]。

一方、リピーターは信号強度を保持できず、オフ信号が送られると信号強度「0」を出力して、オン信号が送られると信号強度「15」にリセットして出力します。このように、RSダストとコンパレーター以外のブロックはすべてデジタルな動きをするわけです。

なお英語圏では、信号強度のことを「ss」や「pl」と略すことがあります[4]。主に見かけるのは「ss」のほうで、たとえば「ss10」は「信号強度 10」を意味するので覚えておきましょう。

03. 動力源化 ( powered )

動力を生みだす方法や動力源となるブロックの話に移りましょう。ブロックのなかには、もともと動力を生みだすために用意されたもの（ボタンなど）もあれば、そうではないものもあります。ただ動力を生みだせないブロックでも、その種類によってはオン信号が送られることによって動力源の代わりになるブロックもあります[5]。それはRSブロックのように、隣接するリピーターやトラップドア等々に対してオン信号を伝えることができるようになるわけです。これを「動力源化」と呼ぶことにしましょう。

動力源化できる種類のブロックは「導体ブロック」あるいは単に「導体」と呼ばれています[6]。たとえば、丸石、RSランプ、ドロッパーなどは導体です。一方、ガラス、半ブロック、ピストンなどは動力源化できない「不導体ブロック」あるいは単に「不導体」と呼ばれ、オフ信号しか通さない絶縁体として働きます。いずれにしても、信号強度が維持される点に注意してください。

なお任意のブロックが導体か不導体かまとめて知りたい場合は〈赤石素子分類｜I-04〉もしくは《赤石素子一覧｜I-05》をご参照ください。

さて、オン信号が送られた導体は動力源の代わりになるわけですが、何のブロックによってオン信号が送られたかにおうじて、オン信号をまわりにどう伝えるかが変わってきます。とりわけRSダストにオン信号を伝えるか伝えないかが変わってきます。この違いを理解するために「強-動力源化」と「弱-動力源化」というふうに区別して確かめていきましょう。この区別をうまく使えば回路を思いどおりに組みやすくなります！

強-動力源化 ( hard-powered )

リピーター、コンパレーター、オブザーバーなどによって直接オン信号が送られた導体は「強-動力源化」します[7]。この状態だと、隣接するトラップドア等々だけでなくRSダストにもオン信号を伝えることができます。ただし、他の導体を動力源化することはできません。オン信号を新たに「生みだす」のではなく、送られたオン信号をまわりに「伝える」「通す」ことしかできないという点に注意してください。

弱-動力源化 ( soft-powered )

RSダストによって直接オン信号が送られた導体は「弱-動力源化」します。この状態だと、隣接するトラップドア等々にオン信号を伝えることはできますが、別のRSダストにはオン信号を伝えることができません[8]。もちろん、他の導体を動力源化することもできません。弱-動力源化の場合、裏を返せば、オン信号をRSダストに伝えないまま他のブロックに伝えることができるので、この範囲の狭さをうまく使って回路を組むこともよくあります。

04. 活性化 ( activated )

ブロックのなかには、送られた信号に反応できるものがあります。たとえばTNTがオン信号に反応して爆発する、ピストンがオフ信号に反応して縮み始める等々です。このように、ブロックの種類によっては信号に反応して起動する、特有のアクション（状態や外見が変わるなど）を起こすものがあります。これを「活性化」と呼びます。

活性化できる種類のブロックを「起動素子」と呼ぶことにしましょう[9]。たとえばRSランプ、ピストン、レールは起動素子です。繰り返しになりますが、ブロックの分類をまとめて知りたい場合は〈赤石素子分類｜I-04〉もしくは《赤石素子一覧｜I-05》をご参照ください。

ここで注意が必要なのは、起動素子かつ導体である（活性化もできて動力源化もできる）ようなブロックがあることです。これに該当するのはRSランプやドロッパーで、状態としては以下の 4 通りの組み合わせがありえます[10]。順に考えてみましょう。

状態 ① ② ③ ④
活性化 - ✓ - ✓
動力源化 - - ✓ ✓
4 STATES
  • ① 活性化も動力源化もしていない状態
    これはオフ信号が送られている状態です。特筆することはありません。
  • ② 活性化しているが動力源化していない状態
    これはたとえば導体を介してオン信号が送られている状態です。
  • ③ 活性化していないが動力源化している状態
    これは一見「矛盾」しています。というのも、オン信号が送られることによって動力源化しているはずなのに、なぜかその信号に反応せず活性化できていない状態だからです。そのため不可能なように思われますが、実際はそうではありません。すぐ後述します。
  • ④ 活性化も動力源化もしている状態
    これはたとえばリピーターによって直接オン信号が送られている状態です。③のような「矛盾」はありません。

以上、起動素子かつ導体であるようなブロックの 4 通りの状態を確かめました。その結果「③活性化していないが動力源化している状態」は一見すると「矛盾」していて不可能だと思われましたが、実際は可能であると述べておきました。

この点を理解すること——この「矛盾」が矛盾ではないと理解して、不可能を可能にすること——こそ、赤石基礎論を理解するための第一歩としてふさわしいものです。次項で明らかにしていきましょう。

05. 起爆剤 ( activation trigger )

活性化というのは、信号に反応して起動することでした。ただ起動素子が実際に動き始める、つまり「起爆」するためには信号が送られるだけでは不十分で、その信号に反応するための「起爆剤」も必要になります。その起爆剤のことを「隣接更新」と呼びます。

起動素子は、隣接更新を受け取らないかぎり活性化することはありません。言いかえると、起動素子自身が今どのような状態になるべきか（オン信号が送られているかどうか、活性化すべきかどうか）は隣接更新を受け取ってはじめて判定されるわけです。一般にマインクラフトの世界では、あるブロックの状態が変化するには隣接更新が必要です[11]。

一方、動力源化については隣接更新が不要です。要するに、オン信号が送られて動力源化したものの、何らかの理由で隣接更新を受け取れなかった起動素子は活性化できていない状態になりうる、ということです。電源にはつながれているのに電源ボタンが押されていない状態といってもよいでしょう。この「信号と起爆剤の分離」という仕様をうまく使うことで、先ほどの「③活性化していないが動力源化している状態」をつくりだすことが可能になります。

逆に、活性化したあとにオフ信号が送られていても何らかの理由で隣接更新を受け取れなかった起動素子は、まわりの変化に気づかず活性化したままの状態になります。このように、隣接更新を受け取ったブロックは自身の状態を「アップデート」させようとします。

信号変化 ＋ 隣接更新 → 状態変化（アップデート）

おわりに

オン信号とオフ信号の区別から始まり、信号強度、動力源化とその区別、活性化を通して、赤石の核心に踏みこむ起爆剤（隣接更新）にまで辿り着きました。本論の最後に触れた「信号と起爆剤の分離」という仕様は、赤石において極めて重要な意味をもっています。詳細は〈隣接更新｜I-03〉をご参照ください。

なお活性化に関連して「信号と起爆剤の分離」を語るときに避けられないのは、「信号とブロックがどう接続するか」という配線の問題です。あわせて起動素子のなかでもピストン、ドロッパー、ディスペンサーだけは例外的な性質をもっていることも問題になります。この仕様については次の〈信号接続｜I-02〉で詳述して、配線技術については〈赤石回路設計法｜IV-Arch〉で触れる予定です。
